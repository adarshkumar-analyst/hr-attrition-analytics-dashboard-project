# HR Attrition Analytics Dashboard

An end-to-end Excel analytics project analyzing employee attrition patterns, 
compensation equity, and workforce engagement using a synthetically generated 
HR dataset (8,000 employees, 35 attributes).

## 🎯 Objective
Identify the key drivers of employee attrition and surface actionable 
retention insights through interactive dashboards and deep-dive analysis.

## 🛠️ Tools Used
- Microsoft Excel (PivotTables, PivotCharts, Slicers)
- Power Query (data transformation, bucketing)
- DAX (Power Pivot measures)

## 📊 Dataset
- 8,000 employee records, 35 columns
- Covers demographics, compensation, tenure, satisfaction, and attrition
- Synthetically generated with realistic correlations (e.g. OverTime → 
  higher attrition, JobLevel → income, tenure-consistent promotion history)

## 📁 Project Structure
- **Raw Data** — source dataset
- **Backend (Pivot Tables)** — calculated KPIs feeding the dashboard
- **Dashboard** — visual summary (KPIs, attrition drivers, compensation, demographics)
- **Deep-Dive Report** — detailed pivot tables with written insights

## 🔑 Key Insights
- Overall attrition rate: **19%**
- **Work-Life Balance (25%)** and **Better Offer (22%)** are the top two 
  attrition reasons, together explaining ~47% of all exits
- Overtime employees show a sharply higher attrition rate than non-overtime
- Salary hikes are nearly flat across performance ratings (12.4%–12.7%) — 
  no strong pay-for-performance link
- No gender pay gap found — compensation is driven purely by job level
- Career stagnation (years since promotion) is **not** a significant 
  attrition driver in this dataset

- Review performance-based hike structure to better reward top performers
